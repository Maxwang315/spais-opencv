# SPAIS OpenCV 

Beginner OpenCV stuff for the SPAIS robot project.

- `lesson1.py` – images as NumPy arrays, BGR, reading/writing/showing images
- `lesson2.py` – color spaces (grayscale, HSV) and color masking with `inRange`

## Setup
    pip install -r requirements.txt

Lesson 2 needs a photo: put one in this folder and update the filename in `cv2.imread(...)`.
